# 独立作者表达包 · v2.3

包版本仍为 1.0.0，产品为 2.3.0。PROFILE 为入口；judgment、language、lexicon 与 rubric 描述判断、语言、词汇及审稿。manifest 白名单固定七份规则文件，连同 manifest 导出八个普通文件。README 不在导出白名单中，文档更新不改变表达规则。

运行 python3 scripts/export_author_profile.py --out dist/touge-author-expression-1.0.0.zip。原始公众号语料及蒸馏过程保持私人；后续作品反馈不自动写回本包。
