## 交付

- 公众号短篇／单篇和小说长篇／连载两个 Skill，按任务组合原子方法。
- JSON 与 JSONL 来源适配、事件／别名检索、实际读取范围记录及多对多素材使用映射。
- 输入、方法和阶段锁定；正文、试写、审稿分离；中断可用同操作 ID 对账恢复。
- 语义重复、作者声音和事实／虚构约定进入写作及实际审阅，而非只清点文件。
- 全部产品入口、模块 README、技术文档与模板按最终实现更新；原辅助入口兼容。
- 完整公共 ZIP 和独立作者包；workspace 仅在本地初始化，不包含个人作品和原始语料。
