# v2.0 测试与验收

验收对象是产品能力、迁移完整性和外部操作证据。真实书稿的事实、情节和文学质量不属于升级验收；新写作评测使用合成资料。

## 公共可复现检查

在 Git checkout 中运行：

```bash
python3 -m unittest discover -s tests -v
python3 scripts/preflight_check.py
```

单元测试使用临时合成作品，覆盖继承、隔离、不可覆盖、并发锁、篡改检测、备份恢复、路径边界、分享包和操作记录。v2.0 基线为19项。预检检查 Git 索引及未忽略候选文件，包括被强制加入 Git 的私人路径；关键词扫描只能提供启发式泄漏检查。

## 本次完整发布验收

```bash
python3 scripts/acceptance.py --workspace workspace
```

[验收清单](../configs/acceptance.json)包含12组检查：单元测试、公共边界、源迁移、工作副本、语料、版本与进度恢复、作者包、上下文与检索、Skill 结构、独立行为、腾讯文档实测、完整备份恢复。

该脚本针对本次迁移证据，不是任意新用户都必须构造的测试环境。它读取已保存的真实云端回执，不会重新发起云端写入；检查通过不代表每次运行都重新验证了账号在线状态。公共克隆没有私人档案和账号证据，无法重放全部迁移验收，不应伪造数据补齐。

`workspace/acceptance/report.json` 是机器结果；详细日志、真实回包、归档和恢复凭证保持私有。只有全部范围内检查通过，才具备 v2.0.0 的发布条件；发布还需确认提交、标签和 Release 一致。

## 外部服务范围

腾讯文档的证据包含既有 Word/表格读取、空间目录、受控 Word 创建、更新与完整回读。结果绑定实测账号和工具版本，不保证所有账号权限与文档类型。

微信公众号 MCP 按已确认范围只建立能力与接入约定，真实连接和操作不验收。这是明确排除项，不能写成实测通过。

## 行为测试与内容使用

早期独立行为测试留下了真实作品的路由和阶段恢复证据。本次发布只采用能力行为证据，不采用书稿内容结论作为门槛。后续新增行为评测使用合成作品，不为升级自动审阅作者书稿。

`evals/tasks.jsonl` 是场景清单，不是自动执行模型的测试器。`evals/outputs/` 是保留的合成样例，不能据此断言 v2.0 对所有写作任务都达到作者偏好。风格打分和结构扫描也不能替代实际使用中的作者审阅。

文档更新还需检查公共包内链接、命令参数及全新安装初始化流程；测试只验证程序与文档，不推进私人作品的写作阶段。
