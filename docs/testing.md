# 测试与验收 · v2.1

三种证据分别报告：确定性程序检查、真实文本的方法评审、作者审美认可。脚本成功不等于文学质量认可，合成输出也不替作者验收自己的书稿。

## 普通安装自检

```bash
python3 -m unittest discover -s tests -v
python3 scripts/preflight_check.py
python3 scripts/acceptance.py --public-only
```

public-only 检查旧接口、新状态行为、13 张能力卡、冻结任务、六组实际写作样本和公共包干净安装。它不读取作者私人工作区或连接账号，也不声称完成迁移和外部服务验收。无 Git 的官方完整 ZIP 使用 release-manifest 校验；自动 source archive 建议改用 Git checkout。

## 维护者完整验收

```bash
python3 scripts/acceptance.py --workspace workspace
```

v2.1 报告写到 workspace/acceptance-v2.1，旧 v2.0 的 acceptance 回执保留。v2.0 的 12 组迁移／连接证据只作为旧功能回归，新版本 A01–A13 单独统计。

| ID | 验收范围 |
|---|---|
| A01 | 旧接口、辅助场景、上下文导出与作者包 |
| A02 | 公私边界与无 workspace 的干净安装 |
| A03 | JSON/JSONL、别名检索、正文阅读与事实判断分离 |
| A04 | 多对多映射、章身份与显示章号分离 |
| A05 | 来源冲突、授权重构、纯虚构与局部推进 |
| A06 | 六组冻结写作任务的实际输出与最低交付要求 |
| A07 | 同义感悟、作者声音、保留项与修改证据 |
| A08 | 任务阶段、试写与内容接受分别记录 |
| A09 | 方法快照、漂移、重试、继承及派生视图 |
| A10 | 私人原件完整、全量恢复与副本回滚 |
| A11 | 新文章和新小说独立运行、无旧作品事实依赖 |
| A12 | 腾讯文档证据覆盖；公众号明确未实测 |
| A13 | 文档链接、命令、版本与发行资产一致 |

六组案例为公众号直接成稿／改写、真实经历式冲突／材料不足、纯虚构连载／改写。任务预期先冻结，输出包含足量正文、审稿、失败及修订。方法卡的例子可见，因此是有提示的有界验收，不是盲测、泛化基准或 WorkBuddy 性能比较。生成者自审与独立复读关系在结果中说明。

腾讯文档协议未变时核验既有真实读写回执，标注沿用历史证据；若改连接、目标定位、写入或回读，则须实测受影响操作。微信公众号依用户明确范围，只建能力与说明，不做账号／读写／发文验收。100% 只指所列范围全部通过，不代表每次写作皆合审美。
