# v2.3.1 命名与工作区定位

公共项目更名为 `touge-writing`。它提供公众号与小说两项写作 Skill、共享作者表达、13 项原子方法和配套工具。私人 workspace 可以同时管理公众号单篇和多部小说；访问某个私有 Git 仓库意味着能读取该仓库已经提交的全部内容，不同共享范围需要分别安排。

根 Skill 的调用名称为 `$touge-writing`，`$touge-wechat-writing` 与 `$touge-novel-writing` 保持不变。新完整包使用 `touge-writing-2.3.1.zip` 和同名版本目录，作者表达包保持 1.0.0。历史版本的旧名称与发行附件不重写。

本版没有改变作品索引、版本登记或任务事件格式，不重新采纳稿件，也不因名称变化自动收集个人语料。详见[更名迁移](rename-v2.3.1.md)。

完整验收继续使用 C01–C10，报告单独保存在所选 workspace 的 `acceptance-v2.3.1/`；公共自检使用 `work/acceptance-public-v2.3.1/`。旧版报告保持原样。腾讯文档的既有读取、历史写入凭证及公众号实测排除范围均延续，不将本轮命名验证写成新的外部写入测试。
