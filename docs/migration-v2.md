# 从旧宿主导入本地作品

此页保留早期 v2.0 导入路线，当前增量升级见 [v2.1](migration-v2.1.md)。导入目标是本地 workspace，不是把个人资料打包进公开项目。

先列出旧专家配置、全书方案、独立章方案、作者决定、当前正文、过程版本、镜像和语料；将来源冻结成清单，再使用 migrate_workspace.py 的 --help 所示命令复制、核对。原件和历史不可覆盖，归档内容不是现行指令。

建立 catalog 与内容 revisions 登记时，以真实作者决定选择当前版本；不用文件名最大值或修改时间判断。章节方案保留当时继承的全书方案，不改成现行最新。来源缺失单独列账，不能称已恢复。云端副本通过宿主读取并保存回执，不假定链接可写。

新语料沿用显式索引，个人原文不放测试目录。导入后 validate、resume、完整备份与独立恢复；未知阶段只记未知，不补造审批。迁移授权不意味着可以改正文或完成章节 review。
