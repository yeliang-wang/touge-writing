# v2.0 微信公众号连接能力

面向后续接入公众号服务的使用者。v2.0 按确认范围只建立能力与操作约定，不安装或选定某个实现，不连接账号，也不进行真实操作验收。状态为 `documented_not_live_tested`。

## 需要核对的服务能力

| 操作 | 核对内容 |
|---|---|
| 账号查询 | 明确账号标识及可用权限 |
| 文章与素材读取 | 分页、正文完整性和时间覆盖；发布接口不一定支持全部历史文章 |
| 上传素材 | 区分封面、正文图片和其他素材，保存源文件摘要与返回 ID |
| 草稿创建、读取、更新 | 绑定本地文章版本，更新前读取指定目标 |
| 发布提交与状态查询 | 选定账号与稿件；查询最终结果与发布链接 |

安装具体服务时，核查其来源、许可、依赖、认证方式和账号要求。工具名称与输入字段以该服务的 tools/list 为准；本页操作名称不是已经实现的统一 API。

## 使用流程

本地 Markdown 稿件 → 按需生成排版和图片 → 指定账号的草稿 → 按发文指令提交 → 查询结果并记录。公众号写作本身可离线完成，不强制连接平台。

用户只要求生成文章时交付稿件；要求草稿时只处理草稿。发布提交、发布成功与订阅者群发是不同结果，不能混称。实际调用必须沿用明确的账号、版本、目的地和操作授权。

超时记录 unknown，依据返回的草稿或发布 ID 查询后再决定是否重试。远端编辑与最后同步内容不一致时记录 conflict。授权值放在宿主，作品只保存必要标识与操作回执。

后续真实接入形成独立验收记录，不回填成 v2.0 已完成的实测。
