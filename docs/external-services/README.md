# 外部服务连接 · v2.3

MCP 只连接外部服务；模型执行、授权与凭据由 Codex 宿主负责。方法和本地写作进度不依赖联网。Git/GitHub CLI 管理私有作品版本，不要求 GitHub MCP；下列 MCP 均为按任务选择的外部连接。

| 服务 | 本版本状态 | 说明 |
|---|---|---|
| 腾讯文档 | 可选导入、审阅、导出或历史读取；写回协议沿用历史验证 | [配置与范围](tencent-docs.md) |
| 微信公众号 | documented_not_live_tested；只建立连接与操作能力约定 | [能力说明](wechat.md) |
| 后续 MCP | 按实际服务注册宿主工具与能力说明 | [扩展步骤](adding-service.md) |

文档化、配置、认证和已实测分开表达；一个读请求成功不证明所有写操作。run 的本地完成不产生外部操作，外部记录也不改变正文是否 accepted。账号别名、远端 ID 和必要回执私有保存；密钥不进入仓库和 workspace。

各人使用自己的宿主凭据，只有选定内容进入远端服务。私人记录保存在本次明确选择的 workspace；推荐路径与旧 CLI 兼容见 [安装](../installation.md)。使用 Git 为正式存储时，腾讯文档不再承担另一份自动定稿状态；云端修改先形成快照与差异，再由主编审阅登记。[合作](../collaboration.md)
