# v2.4.2：统计口径与协作审阅

本补丁修正真实使用中暴露的工具和指导缺口。v2.4.1 已有的有据扩写、自然分段、语义重复审阅和初稿里程碑继续有效；没有新增写作类别、运行框架或工作区 schema。

| 问题 | 本版处理 | 兼容边界 |
|---|---|---|
| 引用行可能是正文，也可能是编辑说明 | 正文检查新增显式正文／排除行范围，报告范围与源哈希 | 默认 legacy 复现旧结果；新任务主动选 explicit |
| 一个因果单元被全部算为当场场景 | 审稿 1.0.2 分开定位铺垫、当场叙述、后果、回望，说明分子与分母 | 不添加公共比例门槛，旧方法不覆盖 |
| 合作署名与素材经历混淆 | 章节和合作模板按需区分经历主体／叙述者、素材作者、执笔者与确认权限 | 可选字段，不改变内容登记格式 |
| 正常登记被误判为快照损坏 | 指导核对旧条目、正文哈希、新增条目和实际登记来源 | drift 仍报告，不静默豁免、不重写快照 |

仍为 13 项原子能力，注册表 17 个版本条目；新增 `editorial-review@1.0.2`，两项 Skill 的新任务组合引用它。旧 run 使用原快照，作者表达包保持 1.0.0。

## 私人作品更新

已有作品有新作者决定时，另建私有规则版本并接入统一入口，记录真实来源、目标与任务范围。局部的编号收获、篇幅要求或段落例外不能推广成全书默认，也不能进入公共作者风格。作品可以独立升级规则而保持正文、历史方案、版本登记和里程碑状态。规则修订号不等于公共产品版本或文学版本。

## 验证和发行

执行 [D01–D06](testing.md)，使用 `configs/acceptance-v2.4.2.json`、`evals/v2.4.2` 和单独的验收输出。单元回归检查范围统计与兼容；独立 Agent 使用合成小说、公众号及登记恢复请求验证实际判断。保留历史证据，不在产品升级期间改写或重新验收真实书稿。

发布前完成适用 D01–D05，发布后核对公共／私有远端克隆、标签和发行资产完成 D06；具体通过状态以执行报告为准。外部协议未改，腾讯文档只核验历史凭证，微信公众号账号操作继续按用户范围排除。
