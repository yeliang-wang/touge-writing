# v2.3.0 发布验收

v2.3.0 增加独立私有作品仓库和候选包协作。公共仓库与发行 ZIP 只包含能力、模板、脚本、文档及合成验证材料，不包含真实作品。

## 变化与边界

`scripts/git_collaboration.py` 将贡献保存为新增候选包，绑定正式提交、方案、正文和作品指纹。`guard` 与 `verify` 拒绝改动正式记录或使用过期基线。主编获取远端最新正式分支后审阅候选、顺序登记；合并不是作者确认。工具不会自动获取远端、推送、邀请成员或合并书稿。

已有本地 workspace、版本登记、任务事件、13 项原子方法及作者包 1.0.0 继续兼容。用户可选择独享 workspace、独立私有仓库或按授权使用外部文档。详见[迁移指南](migration-v2.3.md)和[协作协议](collaboration.md)。

## 验收口径

当前门禁见 [C01–C10](../configs/acceptance-v2.3.json)。公共安装执行 `acceptance.py --public-only`，只核验公开能力；完整迁移验收需要所有者提供的私有原件、备份、历史外部凭证和实际私有远端。两者的报告分别保存，不覆盖旧版本证据。

六项协作行为评测使用合成作品与本机独立 Git 克隆，涵盖重新克隆、候选完整性、主编登记、基线变化、并行正式修改拒绝和恢复。它不是多个真实 GitHub 账号的权限验收。公开证据位于 [v2.3 评测](../evals/v2.3/git-collaboration/README.md)。

腾讯文档写入协议未变，写入能力复核既有真实凭证；本次迁移重新读取当前文本文档并比对归档，不宣称新增写入测试或云端评论、排版、附件的完整迁移。公众号账号连接与实测继续按既定授权排除。私有仓库提供访问控制，不实现应用内加密。
