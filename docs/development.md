# 开发约定 · v2.1

先分清改动属于方法、状态工具、作者表达还是某部作品。公共源只接受去除作品事实的规则、合成测试和技术文档；真实反馈先保存在私人区。项目根 AGENTS.md 与两项 Skill 为路由入口。

## 改写作方法

新增能力版本目录并更新 registry 的路径、语义版本和 SHA-256，保留已发布版本。卡片必须写适用范围、输入输出、完成条件、失败处理、事实／虚构约束和合成例子。Skill 只编排与引用。作者包有自己的 manifest；没有改变表达规则不因产品升级升版。既有 run 快照不可覆盖。

方法变化用实际写作案例检查。评测任务及最低条件先冻结；保留失败稿和修订，不事后放宽标准。独立评审与生成者自评如实区分，公开例子可见的验收不称盲测。

## 改确定性工具

复用 workspace_lib 的路径范围、不可覆盖复制、单机锁和原子写入。内容登记 schema 1 与 v2.0 兼容，未知未来 schema 拒绝写入。任一新状态先明确其唯一权威数据，state 文件只能派生。测试异常恢复：复制后未记事件、正文登记后未记事件、相同操作 ID 换输入、锁冲突、路径逃逸。

```bash
python3 -m unittest discover -s tests -v
python3 scripts/preflight_check.py
python3 scripts/acceptance.py --public-only
```

公共代码不依赖某本私有小说存在。辅助命令继续回归，公开上下文导出禁止混入 run/素材/凭据。涉及 MCP 连接或写回协议的变更须追加对应真实外部证据，单元测试不能替代。[验收](testing.md)
