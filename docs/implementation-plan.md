# v2.0 交付范围

本页是 v2.0 的实施范围说明，实际结果由验收记录与 GitHub Release 表示。

## 产品组成

交付共享作者能力、公众号写作 Skill、小说写作 Skill，以及文件式私人工作区管理工具。Codex 负责执行和外部连接。保留旧路由与辅助功能，并将项目入口、模块说明、技术文档统一到 v2.0。

## 数据与发行

公共仓库发布方法、脚本、模板、技术文档和审阅后的风格抽象。工作区在安装后本地创建或迁移导入，私人作品、原始语料、历史档案、账号配置与云端回执不随仓库或 Release 发布。作者能力包单独导出。

## 外部服务范围

腾讯文档需要真实读取、既有文档兼容核对、受控写入与回读。微信公众号按确认范围仅建立能力与接入约定，不进行账号连接或真实操作验收。新增 MCP 服务仍由宿主管理。

## 升级与使用的边界

迁移保存来源、版本关系及已确认决定。恢复工作阶段只证明进度恢复正确，不自动执行该阶段的内容任务。书稿事实、情节、正文和章节方案审阅属于发布后的独立写作任务；早期测试中的内容观察不作为发布待办或作者决定。

## 交付顺序

核对公共代码与文档 → 执行[测试与验收](testing.md) → 从 Git 公开文件构建并检查发行物 → 提交、标签及 GitHub Release → 核对远端版本和下载资产。

版本号、Git 标签和 Release 必须对应同一个发布提交。完整条件见 [configs/acceptance.json](../configs/acceptance.json) 与[发布流程](releasing.md)。
