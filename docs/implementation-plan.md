# v2.3 实现范围

本版本沿用既有写作方法、内容登记和 lifecycle，增加独立私有作品 Git 协作。公共能力项目与作品仓库分别维护，腾讯文档成为可选外部渠道。实际交付以发行记录和验收报告为准。

| 方案落点 | 实现 |
|---|---|
| 独立私人作品仓库 | 明确 --workspace；作品按相同访问范围单独入库 |
| 旧行为兼容 | 单机本地用法、现有内容工具与相对默认值保留 |
| 候选提交 | git_collaboration.py package，绑定共同提交、内容登记与选用版本 |
| 贡献边界 | guard 检查只新增完整候选包，拒绝夹带正式文件修改 |
| 基准审查 | verify 核对包、当前登记与方案/正文；漂移时重新审阅 |
| 正式整合 | 主编顺序使用既有 add-revision / run register；实际作者决定保持独立 |
| 个人过程 | 独立本地副本保存个人 run/lifecycle，不合并到正式链 |
| 迁移 | 来源读取核对、共享范围清单、全量备份、私有远端和克隆验证 |
| 可选外部工具 | Git/GitHub CLI 足以协作；腾讯文档保留导入/导出和历史读取 |
| 验收 | acceptance-v2.3.json：公共 C01–C07，完整 C01–C10；历史证据独立 |
| 发布 | 公共能力完整 ZIP、独立 1.0.0 作者包，不含真实作品 |

13 项原子能力、素材映射、输入快照和恢复规则继续有效。方法卡、作者包及作品方案没有内容变化时不随产品升级升版。候选包是审阅单位，PR 合并不是作者接受正文。

不新增常驻同步服务、多人自动正文合并、分布式锁、应用层加密或全局目录定位配置。本地 guard 是审阅辅助，不能代替仓库成员与分支权限。迁移只核验完整性及恢复，不重写真实章节。
