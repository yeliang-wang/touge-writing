# 有边界的素材发现

ID：`material-discovery` · 版本：`1.0.0`

## 目的与适用
用于公众号单篇及小说的相关子任务。已有完整材料只需核对覆盖；禁止默认搜索另一部私人作品。

## 输入与输出
输入：本轮事件或主题、允许的清单、实体与别名。
输出：候选来源、实际阅读全文范围、缺口和检索记录。
参数：作品类型、任务范围、事实／重构／纯虚构约定、必要篇幅；没有参数时遵循本次任务，不继承其他作品配额。

## 方法
按事件、人物、公司、时间和别名组合检索，不只搜章号。用 material_index.py search 发现候选，再用 read 读正文和冲突上下文。保留命中与阅读的区别。既有摘要不能当作全文已读。

## 证据与虚构边界
当前明确任务与已有有效授权优先；在作品约定内细化。来源可追溯不表示事实已确认，接受正文也不代表逐句事实认证。重构依授权范围，纯虚构依设定；未知动机不自动成为真实经历。正文、审稿和作者决定分开。

## 完成条件与材料不足
已读材料确实支撑任务关键动作或判断；不足处列出具体缺口，不保证检索到所有材料。
补一次定向检索、询问关键缺口、缩短为过渡或在既有授权内独立试写；不能用空泛感悟凑字。

## 合成正反例
可用：以“空表 导入 演示”找到标题为“那次返工”的旧文并阅读全文。
反例：只搜“第三章”，没搜到就断言没有材料。

这两个例子只演示方法，不能作为作品素材或固定写法。
