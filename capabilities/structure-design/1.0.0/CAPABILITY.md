# 结构与职责

ID：`structure-design` · 版本：`1.0.0`

## 目的与适用
用于公众号单篇及小说的相关子任务。短修订不用完整全书提纲；不强制编年体或固定几幕。

## 输入与输出
输入：读者约定、有效方案、实际文本及邻近内容。
输出：结构、段落或章节职责、独立新增内容。
参数：作品类型、任务范围、事实／重构／纯虚构约定、必要篇幅；没有参数时遵循本次任务，不继承其他作品配额。

## 方法
先比较实际写了什么，再判断本轮要新增什么。把素材的主叙述与回响分开。章 ID 和显示排序分开；章方案显式继承某一全书方案版本。

## 证据与虚构边界
当前明确任务与已有有效授权优先；在作品约定内细化。来源可追溯不表示事实已确认，接受正文也不代表逐句事实认证。重构依授权范围，纯虚构依设定；未知动机不自动成为真实经历。正文、审稿和作者决定分开。

## 完成条件与材料不足
各部分承担不同工作，切分理由与真实内容相符；无单纯重复结论的段落。
若需改章序或拆合章，交候选结构和受影响范围，原登记不动。

## 合成正反例
可用：上篇写权限误判，本篇写如何验证输入，各有独立转折。
反例：每章统一三段金句，不管素材是什么。

这两个例子只演示方法，不能作为作品素材或固定写法。
