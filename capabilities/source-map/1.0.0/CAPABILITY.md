# 说法、证据与授权

ID：`source-map` · 版本：`1.0.0`

## 目的与适用
用于公众号单篇及小说的相关子任务。纯虚构以设定和连续性为约束；不要求逐句外部引证。

## 输入与输出
输入：来源全文与版本、采用的说法、作品事实及虚构约定。
输出：带行段锚点的最小证据与冲突表。
参数：作品类型、任务范围、事实／重构／纯虚构约定、必要篇幅；没有参数时遵循本次任务，不继承其他作品配额。

## 方法
分开来源身份、可定位证据、作者确认与虚构授权。作者旧文可能含记忆差异。保留冲突版本，标明影响事件；不靠新旧文件名选真相。来源版本到事件到章内用途可多对多。

## 证据与虚构边界
当前明确任务与已有有效授权优先；在作品约定内细化。来源可追溯不表示事实已确认，接受正文也不代表逐句事实认证。重构依授权范围，纯虚构依设定；未知动机不自动成为真实经历。正文、审稿和作者决定分开。

## 完成条件与材料不足
关键事实可定位；推断、冲突、授权重构分得清，阅读记录不伪装事实认证。
冲突只限制依赖它的部分；其余授权工作继续。未决项写进审稿，不随意植入正文。

## 合成正反例
可用：两个记录的年份不同，但空表失败事件一致；先写不带年份的独立片段。
反例：旧表和当前稿都叫第三章，所以是同一章。

这两个例子只演示方法，不能作为作品素材或固定写法。
