# v2.0 自动化测试

运行 `python3 -m unittest discover -s tests -v`。测试只使用临时目录和合成内容，不需要账号，不修改私人书稿。

[test_workspace.py](test_workspace.py) 的19项测试覆盖：迁移幂等与源篡改、路径穿越、不可覆盖复制、历史方案继承、真实确认依据要求、作品隔离、缓存恢复、并发写锁、外部记录状态、备份恢复与恶意路径、结构词标题扫描、作者包白名单及暂存区泄漏检查。

测试中的模拟回执仅验证记录器拒绝不合格输入，不能替代腾讯文档真实验收。实际账号证据由完整 acceptance 单独检查，见[测试说明](../docs/testing.md)。

新增用例验证可观察行为与不变量；不要复制真实作品作为公共 fixture，也不要为升级测试运行真实章节内容审阅。
