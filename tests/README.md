# 确定性行为测试 · v2.4.1

test_workspace 保留迁移、版本、历史继承、隔离、锁、远端回执、备份和作者包行为；test_v21 覆盖双格式来源、映射、读取声明、任务优先、快照漂移和中断幂等。v2.2 测试增加外部工作区、旧默认兼容、不同终端目录、实际路径显示、初始化保护及合作过程与内容确认的边界。v2.3 增加独立 Git 根、候选包完整性、共同基准漂移、贡献边界与 accepted 分离。新材料只使用临时合成作品。

运行 `python3 -m unittest discover -s tests -v`。测试不调用外部账号、不向用户真实推荐目录写入案例，也不将程序布尔值冒充文学质量。v2.1 文本样本保留历史证据身份；v2.2 合作演练需记录实际宿主行为，不能仅检查文档是否包含关键词。

完整验收另外核对限定范围的私人迁移、完整备份恢复、当前云端来源读取与私有远端克隆证据，公共安装不需要维护者作品。各版本报告分开保存，不覆盖 v2.0、v2.1 和 v2.2 已有回执。
