# 运行维护手册 · v2.1

完整安装后用 init 建立本地作品，再通过对应 Skill 执行任务。小任务可直接完成，需多轮恢复、输入锁定或素材冲突时使用 run。共享作者分数只作线索，不让小说套公众号评分阈值。

日常流程是恢复当前任务及有效内容 → 在明确范围找材料并阅读全文 → 按需选方法 → 交付实际正文／方案 → 审读修订 → 保存产物与真实决定。内容与方法都有版本，旧 run 使用快照；正文是否定稿仍看 revisions。

中断后用原 operation-id 和原输入重试。输入换了不能复用 ID；复制完成但未登记时先比哈希，正文登记而事件缺失时补引用。state 缓存可重建，不能手改缓存解决冲突。来源漂移须保留旧版本并更新采用关系，不能删历史掩盖问题。

定期在 workspace 外备份并恢复到新目录核验。远端操作 unknown 先查询回读，不能盲目重发。新增服务只接宿主工具及服务约定，本地写作不依赖网络。

私人反馈形成候选方法，经抽象和合成验证后才进入公共版本；不直接改变作者包。发布需公共测试、私人回归、实际写作评测及发行校验。详见 [维护与开发](../docs/development.md)、[发布](../docs/releasing.md)。
