# 任务与产物契约 · v2.2

本页描述宿主如何使用能力包，不定义网络 API。输入至少包括任务与材料范围；已有作品从 catalog 唯一定位，不混用其他作品人物或事实。

| 请求 | 实际交付 |
|---|---|
| 公众号直接成稿 | 符合材料的完整正文，按需标题／摘要；不先加提纲审批 |
| 公众号改写 | 保留项、新正文、具体删改理由 |
| 全书／章方案 | 读者与职责、材料、结构、事实与虚构范围、明确继承 |
| 小说场景／续写 | 可读行动、反应或状态变化，连续性和未决范围说明 |
| 跨章审稿 | 实际已读范围、时间设定与语义重复定位、保留项和优先级 |
| 交流／Reboot／产品问答 | 判断、依据、代价和行动建议；不编造产品事实 |
| 内容交付包 | slide-plan JSON、按需文章、PPTX 及逐页讲稿 |

篇幅、比例、题记与配额由作品决定。编辑说明与正文分开，平台排版和图片为派生物。只交付独立片段时标明范围；不能靠改称实验回避用户要求的完整稿件。

run.completed 只表示本次交付完成；内容 accepted 来自实际作者决定，外部草稿或发布另按明确操作授权。产品升级只验能力与迁移，不能顺带修改真实书稿。数据与命令见 [workspace](../docs/workspace.md)、[runs](../docs/runs.md)、[CLI](../docs/cli.md)。
