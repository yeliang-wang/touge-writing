# 本轮合成任务规则 v1

<a id="inheritance"></a>
规则依据是 inputs/request.md 所保存的本轮合成作者请求；适用范围仅为本案例。此处是评估 Agent 的任务化整理，不是新增真人作者决定。没有已接受的全书方案或私人长期规则，不虚构继承版本。

<a id="r-facts-voice"></a>
## facts-voice

事实和原有判断不变，保持平实口气和自我犹疑，不添加经历或心理归因。

<a id="r-rhythm-scope"></a>
## rhythm-scope

仅调整分段、承接及重复说理，不要求加长，不写成很多编号标题的教程。

<a id="r-keep-ending"></a>
## keep-ending

结尾逐字保留：先把问题放在桌上，再谈谁更聪明。

<a id="r-candidate-only"></a>
## candidate-only

直接输出完整候选，暂不登记；不增加提纲审批。
