# 本轮合成任务规则 v1

<a id="inheritance"></a>
规则依据是 inputs/request.md 所保存的本轮合成作者请求；适用范围仅为本案例。此处是评估 Agent 的任务化整理，不是新增真人作者决定。没有已接受的全书方案或私人长期规则，不虚构继承版本。

<a id="r-keep-chain"></a>
## keep-chain

保留原章主线、事件顺序和有辨识度的表达；新增资料修正原稿中当夜补好说明的记忆压缩。

<a id="r-source-boundary"></a>
## source-boundary

只能使用本次原章和新增合成资料；不得补造人物对白、分钟数、责任人或未知经过。邻章只读，不修改。

<a id="r-useful-expansion"></a>
## useful-expansion

扩写使处境、选择和后果更充分，新增篇幅须有材料或判断增量；保留原文，不以重复认真说理凑篇幅。

<a id="r-rhythm-reflection"></a>
## rhythm-reflection

按动作和认识变化调整段落，允许长短交错，压缩重复感想，连读转场。

<a id="r-two-takeaways"></a>
## two-takeaways

结尾交付两点与本章事件相连、读者能用的收获，不夸大为普遍保证。

<a id="r-candidate-only"></a>
## candidate-only

直接交付候选，不额外等待提纲审批，不登记为正式正文；候选不代表作者接受。
