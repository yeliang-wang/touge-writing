# 本轮合成任务规则

依据 inputs/request.md；小说另据 inputs/materials-and-collaboration.md。本页仅将本次请求整理为可核对项，不表示真人作者决定。没有已有全书方案，不捏造继承。

<a id="r-body-scope"></a>
## body-scope

文章面向读者的内容含引用；标题、署名、编务段与资料附记不计入篇幅。

<a id="r-judgment"></a>
## judgment

定位说理重复与过满断言，不把材料未支持的保证当作事实。

<a id="r-review-only"></a>
## review-only

只统计并给审阅意见，不润色、不登记新稿、不发表。
