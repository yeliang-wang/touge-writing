# 本轮合成任务规则

依据 inputs/request.md；小说另据 inputs/materials-and-collaboration.md。本页仅将本次请求整理为可核对项，不表示真人作者决定。没有已有全书方案，不捏造继承。

<a id="r-source-boundary"></a>
## source-boundary

未知人物动机不能写成已知事实，素材只限本请求和录音摘记。

<a id="r-reflection-scope"></a>
## reflection-scope

保留犹疑，收获与材料支持的范围相称；重复结论应指出而非替作者改稿。

<a id="r-review-only"></a>
## review-only

仅交审阅、比较与修改优先级，不改正文、不登记新稿、不替作者定稿。

<a id="r-comparison"></a>
## comparison

现稿和所附完整参考稿使用同一正文口径比较；引用便条属正文，编务和附录不计。

<a id="r-roles"></a>
## roles

以合作记录确认角色，正式章节署名仍待定，不从素材整理署名推断章节作者。
