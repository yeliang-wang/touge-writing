# 写作评测 · v2.3

tasks.jsonl 与 outputs 保留辅助场景历史样本。v2.1/protocol.json 在实现前冻结六组合成请求、原始材料、可用修订次数和最低交付标准；结果保存在 v2.1/results。

评测要求实际正文及文本位置证据，不能仅断言某个词存在。案例覆盖来源冲突、不同章号、授权重构、薄材料、纯虚构和换词重复。原子卡含相关合成示例，所以这些是有提示的有界验收，不是盲测或跨宿主质量排名。模型信息不可得记 unknown；自评与独立复读分开。

不把真实作者书稿或云端回执复制进公共测试。

[冻结协议](v2.1/protocol.json) · [验收说明](../docs/testing.md)

v2.2 新增外部工作区和合作流程的独立合成推演，保存在 `v2.2/`。它们验证任务处理、版本保留与冲突处置，不代表多账号真实腾讯文档并发实测，也不对真实作者书稿作新的接受决定。六组 v2.1 正文证据保持原样。

v2.3 在 `v2.3/` 保存私有 Git 协作的合成验证，区分共同提交、个人运行、候选包和主编确认；实际调用工具并保留结果。它不证明真实协作者已邀请或账号已验证，也不改变旧写作质量结论。
