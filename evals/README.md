# v2.0 行为评测场景

[tasks.jsonl](tasks.jsonl) 保留旧辅助场景并增加公众号和小说场景。旧记录使用 prompt/acceptance，新增记录使用 input/expected；它们都是人或宿主执行的行为要求，不是统一模型评测 API。

场景覆盖文章、交流、改稿、Reboot、标题、产品问答、PPT、小说进度恢复、历史继承及来源冲突。新执行使用合成作品，观察任务路由、阶段遵守、来源使用及版本保护，不把作者真实书稿审阅当产品测试。

`outputs/` 中保留既有合成输出作为兼容样例。历史风格得分不能直接作为 v2.0 全能力通过的证据，当前工程验收见[测试说明](../docs/testing.md)。

评测反馈通过 record_feedback.py 保存到私人目录，稳定且有依据的规则再进入共享资料；一次样例偏好不会自动升级为作者全局规则。
