# 写作评测 · v2.1

tasks.jsonl 与 outputs 保留辅助场景历史样本。v2.1/protocol.json 在实现前冻结六组合成请求、原始材料、可用修订次数和最低交付标准；结果保存在 v2.1/results。

评测要求实际正文及文本位置证据，不能仅断言某个词存在。案例覆盖来源冲突、不同章号、授权重构、薄材料、纯虚构和换词重复。原子卡含相关合成示例，所以这些是有提示的有界验收，不是盲测或跨宿主质量排名。模型信息不可得记 unknown；自评与独立复读分开。

不把真实作者书稿或云端回执复制进公共测试。
