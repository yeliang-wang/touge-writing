# v2.2 合作流程演练

两个场景均为独立评估 Agent 设计并执行的合成任务。先冻结任务和来源，再使用当前 Skill 与实际 CLI 处理；这不是盲测，也不是文学质量评分。

- `novel-shared-baseline-conflict`：两份独立工作区、已确认方案继承、继续写作与提交前共享基准变化。
- `wechat-confirmed-import`：有权编辑明确确认某一版本，云端有更新但未确认的版本，导入目标版本并保留旧稿。

全部姓名、稿件、决定和远端标识均为合成材料。未调用网络或真实 MCP，不代表真实多账号腾讯文档协作、云端并发控制、真实作者接受或公开发布已验证。CLI 接受记录验证格式与引用完整性，确认人的实际权限仍由宿主按作品约定核对。

`inputs/frozen.json` 固定执行前的输入哈希。`transcript.json` 包含实际命令、返回码及输出；公开记录将本机测试目录替换为 `<SYNTHETIC_RUN>`，项目根替换为 `<REPO>`。`artifacts.json` 列出每个场景的输入、执行记录、结果和本地登记证据。父代理另行核查后才生成汇总 review。
