# 章节方案 · v2.4 模板

- 作品 ID / 稳定章节 ID / 显示标题 / 本方案版本：
- 继承的全书方案 ID、版本和哈希：
- 实际正文基线、已定稿与最新草稿；摘要依据哈希：
- 本轮任务、授权范围、阶段和实际决定引用：
- 合写／改编时按需填写：经历主体／叙述者、素材作者及来源、章节执笔者、有权确认者及权限依据。不同角色可由同一人承担；未知项注明未确认，不由第一人称或素材署名自动推断。

## 章节职责与新增内容

本章推动什么行动、认识或论证；与邻章怎样分工。

## 材料与结构

来源版本 → 事件／主题 → 使用角色 → 正文版本。记录阅读范围、冲突及其影响；时间阶段不等于章节编号。按素材选择展开、压缩、过渡，不为凑篇幅添加背景。

## 方法及参数

只选需要的原子能力；列出场景、衔接、回望等实际落点和须保留的表达。具体比例和篇幅是本作品选择。

## 事实与小说化约定

哪些按真实来源，哪些允许重构对白动作，哪些属于纯虚构；授权引用和已知硬约束。未决事实不能登记为已确认。

## 规则继承与本章落点

规则正文与索引版本；本章适用的规则 ID；每项在哪一节、场景或审阅步骤落实。继承范围与不适用理由分开写，例外引用真实决定及其有效范围。若尚无索引，以原规则正文标题或锚点核对，不补造历史阅读记录。

## 连续性与语义审阅

人物、事件、时间和设定；邻章已用结论、意象和情绪落点。本章有意回响与冗余复述的区别。

## 章题与待决项

从实际正文提取候选，不能用标题自动改变章身份。问题记录影响范围与是否阻断本轮任务；能独立完成的工作继续。

方案只描述如何写，正文另存。章级细化不能静默修改全书决定；已有作者授权不用重复取得。
