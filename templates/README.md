# 按需模板 · v2.1

book-plan、chapter-plan、wechat-article 帮助组织作品方案，字段按真实任务取舍。run-request、run-review 和 material-map 是脚本输入形状；替换占位说明和实际哈希，不把模板当作作者决定。

每个方案继承明确版本，正文与编辑说明分开。参数来自作品，不能默认复制另一部小说配额。
