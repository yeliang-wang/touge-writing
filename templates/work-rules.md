# 作品规则

作品 ID：使用当前 catalog 中的稳定 ID。规则正文版本及实际确认依据：填写真实记录。本文是规则正文入口；索引只引用位置和适用范围，不维护另一份措辞。

<a id="r-source-boundary"></a>
## 来源边界

真实自述只陈述已提供材料支持的事实；需要进一步核实的内容在审阅中明确标注。来源：本作品已确认的材料使用约定。适用目标与任务：填写实际范围。

<a id="r-reader-purpose"></a>
## 读者目的

文章或章节开头应让目标读者理解本次要处理的问题。检查时引用实际段落并说明效果；具体表达可按文体调整。来源：本作品已确认的读者约定。

<a id="rule-inheritance"></a>
## 继承与例外

记录所继承方案的明确版本、章级细化范围、实际作者决定及例外有效范围。没有例外就写“无”；不要把模板中的合成规则当作用户已经接受的约束。
