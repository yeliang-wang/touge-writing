# 公众号写作 · v2.3

选题、材料、结构或直接成稿、修改、审稿与外部交付准备。当前任务可从 draft 或 review 开始，不固定增加提纲审批；多步修改按需建立 run。

[Skill](SKILL.md) · [方法组合](references/recipes.md) · [生命周期](references/lifecycle.md) · [工作区](../../../docs/workspace.md)

新版任务显式使用选定工作区，推荐 `~/.touge-writing/workspace`；创建和恢复见 [项目安装说明](../../../docs/installation.md)。作品可以位于独立私有 Git 仓库；协作者从共同基准在本地副本写作，提交选定候选包，由主编顺序登记。个人运行链不合并，PR 合并不等于定稿。腾讯文档为可选外部阅读和交付渠道。[合作流程](../../../docs/collaboration.md)
