# 公众号写作模块 · v2.0

面向公众号短篇、单篇文章任务。执行入口为 [SKILL.md](SKILL.md)，通过 `$touge-wechat-writing` 或明确的公众号写作请求使用。

## 输入与产物

输入可为主题、读者、观点、已有稿、参考文章或产品材料。任务决定先提纲还是直接成稿；不强制固定审批次数。输出可包括标题、摘要、正文、来源说明和必要的审阅意见。

作者表达来自[共享能力](../../../shared/author-expression/PROFILE.md)，文章方法见[公众号方法](../../../references/wechat-public-account-playbook.md)。需要私人历史文章时，先检索再阅读原文，不能把片段视为完整材料。

本地作品放在 workspace/wechat 下，使用作品工具登记版本。文章定稿必须关联真实作者决定；平台排版和图片是派生产物，不覆盖创作源稿。

## 连接与限制

本地写作无需外部账号。公众号 MCP 在 v2.0 只建立能力与使用约定，未进行真实账号验收。腾讯文档可用于按需协作；两者均由宿主管理，不由 Skill 启动服务。
