# 写作 Skill 入口 · v2.3.1

两项入口分别处理公众号单篇和小说长篇；它们引用共享方法、作者表达和生命周期定义，不各自复制作品事实。

[公众号](touge-wechat-writing/README.md) · [小说](touge-novel-writing/README.md) · [根路由](../../SKILL.md)

新版任务显式使用选定工作区，推荐 `~/.touge-writing/workspace`；创建和恢复见 [项目安装说明](../../docs/installation.md)。作品可以放入独立私有 Git 仓库。贡献者从共同提交在本地过程副本写作，只提交选定候选包；主编顺序登记正式版本，个人运行链不合并，PR 合并不等于 accepted。腾讯文档是可选导入、审阅、导出或历史入口。[合作流程](../../docs/collaboration.md)
