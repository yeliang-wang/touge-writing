# v2.0 写作 Skill

本项目提供两项主能力，共用仓库根目录的作者资料和脚本。安装与使用需要完整项目。

| Skill | 使用场景 | 模块说明 |
|---|---|---|
| touge-wechat-writing | 公众号单篇、标题、改稿、审稿和发布准备 | [README](touge-wechat-writing/README.md) |
| touge-novel-writing | 长篇小说、连载、全书与章节方案、续写和连续性 | [README](touge-novel-writing/README.md) |

`SKILL.md` 是执行指令；模块 README 是给使用者和维护者的说明；`agents/openai.yaml` 是界面元数据。旧根 Skill 继续做路由和辅助能力入口。

作者风格不等于作品设定。明确作品后从私人 catalog 恢复状态；只有用户的写作任务才能推动内容阶段，升级验收只验证机制。详见[架构](../../docs/architecture.md)和[安装](../../docs/installation.md)。
