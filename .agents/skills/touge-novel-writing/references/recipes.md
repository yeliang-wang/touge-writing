# 按需组合 · v2.4.2

[机器可读组合](recipes.json)给出起点，不要求全部运行。先看任务再读对应能力卡；每次 run 锁定实际选择。公共能力目录在项目根 `capabilities/registry.json`。

| 请求 | 取用方法 | 实际交付 |
|---|---|---|
| 公众号直接成稿 | 读者、来源、结构、作者声音、审稿 | 完整文章，不增加提纲审批 |
| 旧文改写 | 来源、语义重复、回望、作者声音 | 保留项、修订正文与理由 |
| 全书或章规划 | 素材发现、来源映射、结构、连续性 | 职责与明确继承；不改已定稿 |
| 真实经历场景 | 素材发现、来源、场景、背景、回望 | 在授权范围写行动和状态变化 |
| 纯虚构连载 | 场景、衔接、连续性 | 依设定自由创作，不强要文献 |
| 材料很少 | 来源、衔接 | 有依据的短过渡及具体缺口 |
| 跨章审稿 | 连续性、声音、文字卫生、审稿 | 时间设定和语义重复的定位证据 |
| 有据扩写 | 来源、场景／结构、背景、审稿 | 保留原主线或观点，用新材料补处境、选择和后果 |
| 节奏修订 | 场景／结构、回望、审稿 | 连贯的相邻段落与重复解释的取舍依据 |
| 初稿里程碑确认 | 既有内容登记与作者实际决定 | 原版本及哈希绑定的确认；正文未变不重复登记 |
| 标题 | 标题方法 | 少量候选及正文依据 |

适用性先于数量。序章、编年体、结语和后记是作品选择：可借用结构／读者约定／回望方法，但不自动继承另一部作品的配额、人物、题记或致谢名单。

新任务按需使用 `scene-design@1.0.1`、`reflection-shaping@1.0.1`、`editorial-review@1.0.2`；已有 run 继续使用其快照与固定版本。场景方法只在含叙事情节时选用，观点段仍按论证关系组织。修订收益须用实际前后文说明，字数和段落统计仅作描述。
