# 小说写作模块 · v2.0

面向长篇小说与连载任务。执行入口为 [SKILL.md](SKILL.md)，工作方法见[workflow.md](references/workflow.md)。可使用 `$touge-novel-writing` 或明确指定小说和章节。

## 模块职责

恢复作品 → 读取当前方案及必要上下文 → 执行用户指定的计划、写作或审阅任务 → 保存独立版本。共享作者声音与本书事实分开；人物、时间线、叙事视角和虚构授权属于具体作品。

工具根据版本记录恢复状态。章方案继承明确的全书版本，正文定稿继承同章确认方案；更新全书方案不改旧继承。当前章节的旧正文可以作为基线，但不能自动当成新方案定稿。

人物与时间线资料由写作任务维护，CLI 不从正文自动提取事实，也没有自动连续性裁决引擎。机械扫描只报告重复、结构词和标点线索。

## 使用与边界

先在本地初始化小说和章节配置，详见[使用指南](../../../docs/GUIDE)。恢复结果中的阶段只是状态；升级与发布验收不会因此自动审阅真实章节。实际内容工作需独立的写作指令。
